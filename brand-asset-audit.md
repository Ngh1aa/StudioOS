# StudioOS brand asset audit

## Findings

The current `studioos-mark.png` is a large 1920×1920 raster mark with a vivid green textured background, dark geometric frame, cream slash and orange dot. It does not match the Quiet Precision palette, is visually noisy at sidebar/favicon scale, and does not provide a clean transparent brand mark.

The current project cover `studioos-project-architecture.png` is a 2304×1536 warm paper composition with architectural construction lines and a copper block. It is directionally closer to Quiet Precision, but the current asset set needs a more deliberate, cohesive series across all three project cards.

## Chosen refresh direction

Create one transparent logo mark with a dark rail / copper / linen geometry, plus three distinct editorial project covers: architectural grid and folded paper, tactile material swatches, and a restrained motion study. Keep all covers landscape, low text/no text, with enough quiet space for card overlays.

## Local fallback validation

The local fallback set is now available under `assets/` as 1024×1024 transparent logo PNG plus four 1600×1067 landscape cover PNGs. The logo has a clear charcoal open-frame silhouette with a copper point and reads cleanly against the existing copper brand container. The architecture cover preserves the editorial linen, construction-grid and copper-registration language while leaving enough calm space for the card overlay.

The material cover uses distinct linen, sage, blue-teal and copper swatches with clear overlap and depth. The motion cover uses a strong charcoal diagonal and three restrained arcs to make the set feel related without repeating the same composition.
